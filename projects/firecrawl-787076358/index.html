Firecrawl

A web-data API for search, scraping, document parsing, and interaction. It supplies agent-ready content and structured extraction, with both public code and a hosted service.

Utility: Browser automation; kind: infrastructure.

Utilities

  • Convert web pages into Markdown or structured JSON for an agent.
  • Search and retrieve source material for retrieval pipelines.

Who it is for

  • Developers building agents that need web or document context.

Requirements

  • Use a hosted API key or follow the self-hosting documentation.
  • Configure the client SDK and any required deployment services.

Limitations

  • The hosted service includes capabilities beyond the open-source deployment.
  • Extraction can omit content, and website terms still constrain collection.

Cost and privacy notes

  • Hosted API credits, model-assisted operations, and self-hosted infrastructure have different costs.
  • Requests and retrieved documents pass through whichever hosted or self-hosted components you configure.
