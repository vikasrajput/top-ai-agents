Windmill

A code-first platform that turns scripts into workflows, APIs, scheduled jobs, and applications. It can orchestrate agent tasks while keeping ordinary code and review workflows in the loop.

Utility: Workflow and business automation; kind: platform.

Utilities

  • Compose scripts and agent steps into operational workflows.
  • Expose reviewed scripts as interfaces, APIs, or scheduled jobs.

Who it is for

  • Engineering-led teams automating internal processes and applications.

Requirements

  • Deploy the documented Docker Compose, Kubernetes, or hosted setup.
  • Configure worker resources, database access, and required service credentials.

Limitations

  • Community binaries and source builds have different licensing boundaries.
  • Scripts and workers can access production systems; isolate execution and review permissions.

Cost and privacy notes

  • Hosting, worker compute, models, and commercial features are separate cost considerations.
  • Workflow inputs, secrets, logs, and external tool calls need an explicit data-handling policy.
