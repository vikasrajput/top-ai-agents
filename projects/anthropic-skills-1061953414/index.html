Anthropic Skills

A set of reusable task instructions, scripts, and resources for Claude's skills system. These packages extend an existing agent; they are not standalone autonomous agents.

Utility: Skills; kind: skill.

Utilities

  • Study task-specific SKILL.md patterns and supporting resources.
  • Add compatible document, creative, or technical workflows to an agent.

Who it is for

  • Agent users and developers designing reusable task instructions.

Requirements

  • Use a compatible skills-enabled agent and install the desired skill package.
  • Check each skill's dependencies and license before executing bundled scripts.

Limitations

  • The README describes these as demonstration/educational implementations whose behavior may differ from Claude's product.
  • Document skills are source-available, not uniformly open source.

Cost and privacy notes

  • Agent access and models can cost money separately from the skill files.
  • Scripts may process documents locally or call external tools; review the individual skill before sharing sensitive inputs.

Illustrative example (untested)

Illustrative, not tested: install a compatible skill and ask it to inspect a demonstration document, then review the result.

License

Mixed per-skill licensing: many examples use Apache-2.0; docx, pdf, pptx, and xlsx are source-available under their own licenses. No blanket repository license applies.
