Paperclip

An orchestration application for teams of agents, with tasks, goals, budgets, permissions, and history. It manages existing agents rather than replacing their runtimes.

Utility: Agent operations; kind: platform.

Utilities

  • Assign and track work across heterogeneous agent adapters.
  • Review agent costs, permissions, and task history from a dashboard.

Who it is for

  • Technical teams coordinating multiple agents with operational ownership.

Requirements

  • The README requires Node.js 24.11+ and pnpm 9.15+ for the source setup.
  • Configure supported agents, persistent storage, and authenticated production access.

Limitations

  • Adapters have different capabilities and dependencies.
  • Budget/governance controls do not guarantee task success or prevent every tool side effect.

Cost and privacy notes

  • Agent subscriptions/models and deployment resources remain separate expenses.
  • Task history, agent credentials, and connected systems need isolation and retention controls.

Illustrative example (untested)

Illustrative, not tested: connect one test agent, set a bounded task budget, and review its activity before expanding access.
