AnythingLLM

A local-first application for document chat, agent tools, and configurable model connections. Desktop and self-hosted deployments support different operating needs.

Utilities

  • Ingest documents into a conversational workspace.
  • Use built-in agents and memory with local or cloud model providers.

Who it is for

  • Individuals and teams who want a document-and-agent workspace rather than a framework.

Requirements

  • Install a supported desktop application or self-hosted deployment.
  • Choose model, embedding, and storage settings appropriate to your documents.

Limitations

  • Multi-user permissions and some workspace features are deployment-specific.
  • Retrieved document context does not prevent unsupported generated answers.

Cost and privacy notes

  • Local models need hardware; remote providers and hosting can add costs.
  • Local-first does not mean local-only if embeddings, tools, or models use external services.
