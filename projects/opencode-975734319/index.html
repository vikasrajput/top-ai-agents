OpenCode

A coding agent with terminal and desktop interfaces. Its separate plan and build modes let you explore a repository before giving the agent permission to change it.

Utilities

  • Explore unfamiliar code and plan changes in a read-only mode.
  • Implement changes with an agent that can use development tools.

Who it is for

  • Developers who want a configurable coding agent rather than editor-only suggestions.

Requirements

  • Install a supported CLI package or desktop release.
  • Configure access to a supported model and the repository you intend to work on.

Limitations

  • Build mode can change files and execute tools; review permissions and diffs.
  • The desktop application is labeled beta in the reviewed README.

Cost and privacy notes

  • Model-provider usage or subscriptions can cost money independently of the MIT code.
  • Check where the configured provider and connected tools send repository content.

Illustrative example (untested)

Illustrative, not tested: ask plan mode to map a service's request flow, then review a proposed patch before switching to build mode.
