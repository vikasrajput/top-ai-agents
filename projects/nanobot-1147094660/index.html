nanobot

A self-hosted personal agent with browser, terminal, and messaging interfaces. It supports file work, remembered preferences, and scheduled tasks around a configured model.

Utility: Personal agents and workspaces; kind: agent.

Utilities

  • Use a personal agent through a WebUI, terminal, or chat channel.
  • Connect file tools, memory, and scheduled tasks in a smaller deployment.

Who it is for

  • Technical users who want an inspectable personal-agent stack.

Requirements

  • Python 3.11+ and a supported model provider or local model server.
  • Configure the selected channel and deployment; source installs also require Git and Bun.

Limitations

  • Platform wheels and source builds have different runtime requirements.
  • A lightweight framework still needs careful tool, channel, and file-access configuration.

Cost and privacy notes

  • The project supplies no model account; provider usage or local hardware is your responsibility.
  • Memory, channel messages, and file contents may reach the configured model endpoint.
