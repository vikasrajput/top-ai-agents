Dify

A visual platform combining agent workflows, retrieval pipelines, model management, and deployment. Its license adds conditions beyond standard Apache-2.0.

Utility: Workflow and business automation; kind: platform.

Utilities

  • Compose model and tool steps on a visual workflow canvas.
  • Build document-grounded applications with managed model configuration.

Who it is for

  • Teams that prefer an application-building workspace over assembling every component in code.

Requirements

  • Docker Compose setup documents a minimum of 2 CPU cores and 4 GiB RAM.
  • Configure model credentials, persistent services, and production access controls.

Limitations

  • The modified license restricts certain multi-tenant and branding uses.
  • Workflow composition does not remove the need to test tool actions and retrieval quality.

Cost and privacy notes

  • Cloud plans, model calls, and self-hosted infrastructure have separate costs.
  • Review where documents, workflow logs, and plugin calls are stored or transmitted.

Illustrative example (untested)

Illustrative, not tested: build an internal document-answering workflow with a human-review step before publishing its response.
