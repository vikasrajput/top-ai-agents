Hermes Agent

A persistent personal agent with terminal, desktop, messaging, and scheduled-work interfaces. It can create reusable skills and search past sessions, with configurable model providers.

Utility: Personal agents and workspaces; kind: agent.

Utilities

  • Continue tasks across sessions using inspectable memory and skills.
  • Run scheduled workflows or interact through supported messaging channels.

Who it is for

  • Technical users who want an ongoing assistant they can host and configure.

Requirements

  • Install the supported package/application and select a model provider.
  • Configure only the required gateway channels and execution backend.

Limitations

  • Self-modifying skills and persistent memory require periodic inspection.
  • Unattended tasks and remote execution can act with broad access unless constrained.

Cost and privacy notes

  • Model subscriptions/API usage, server hosting, and optional cloud tools can incur charges.
  • Session history, imported credentials, memory, and messaging integrations need clear retention and access boundaries.

Illustrative example (untested)

Illustrative, not tested: schedule a read-only public-news digest and review both its sources and retained memory.
