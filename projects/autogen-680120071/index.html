AutoGen

A historical multi-agent application framework. Its current README says the project is archived and no longer maintained, even though the live GitHub archive flag was unset at collection.

Utilities

  • Study existing multi-agent conversation and orchestration patterns.
  • Understand older AutoGen applications when planning a migration.

Who it is for

  • Maintainers of existing AutoGen systems and researchers studying its design.

Requirements

  • Documented packages require Python 3.10+ and configured model access.
  • Review the Microsoft Agent Framework migration guidance before starting new work.

Limitations

  • The README says Microsoft no longer provides fixes, features, or support and advises against production use.
  • Dependency vulnerabilities may remain unaddressed; stars and an unset archive flag do not establish maintenance.

Cost and privacy notes

  • Model calls and execution environments can incur costs even for historical experiments.
  • Do not process sensitive data without assessing the unmaintained stack and any code-execution tools.
