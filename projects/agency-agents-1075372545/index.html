Agency Agents

A collection of specialized agent personas and workflow instructions. It installs into compatible coding agents and provides role-oriented guidance, not verified professional expertise.

Utility: Skills; kind: skill.

Utilities

  • Reuse role-specific instructions for development and other workflows.
  • Compare and customize persona definitions for a bounded task.

Who it is for

  • Agent users who want starting points for specialized instructions.

Requirements

  • Use a compatible agent or the separately documented installer application.
  • Review selected persona files and adapt them to the task and permissions.

Limitations

  • A specialist title does not establish credentials, accuracy, or tested deliverables.
  • Marketing claims in upstream documentation are not ratings or outcomes measured by this directory.

Cost and privacy notes

  • The MIT instruction collection does not include an agent runtime or model budget.
  • Inputs go through the host agent's tools and providers; specialist prompts are not a privacy boundary.

Illustrative example (untested)

Illustrative, not tested: select a frontend-oriented persona for a demonstration review and independently check its suggestions.
