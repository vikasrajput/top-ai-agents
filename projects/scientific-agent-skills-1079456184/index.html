Scientific Agent Skills

A library of scientific workflows for agents supporting the Agent Skills standard. It covers analysis and database tasks but does not establish that an agent is a qualified scientist.

Utility: Domain-specific; kind: skill.

Utilities

  • Reuse documented scientific-analysis workflows and database guidance.
  • Configure task-specific dependencies rather than installing every scientific package.

Who it is for

  • Researchers who can validate methods, sources, and outputs in their domain.

Requirements

  • Use a compatible skills-enabled agent.
  • Install only the dependencies needed by the selected skill and arrange any database credentials.

Limitations

  • Each skill specifies its own compatibility and validation scope.
  • Generated scientific or medical content needs expert review and is not clinical advice.

Cost and privacy notes

  • Agent models, licensed databases, and optional cloud compute may incur charges.
  • Do not send patient or unpublished research data to external services without an approved policy.

Illustrative example (untested)

Illustrative, not tested: use a database-lookup workflow to find public protein records and independently verify identifiers and provenance.

License

Repository MIT, with individual SKILL.md license metadata potentially adding different terms; review each selected skill. Anthropic document skills are no longer bundled.
