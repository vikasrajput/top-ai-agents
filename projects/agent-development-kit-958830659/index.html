Agent Development Kit

Google's code-first Python toolkit for building, evaluating, and deploying agent workflows. It is optimized for Gemini but documents model- and deployment-agnostic operation.

Utility: Frameworks; kind: framework.

Utilities

  • Compose graph workflows and structured agent delegation.
  • Connect tools and evaluate an agent application before deployment.

Who it is for

  • Python developers who want a modular agent runtime.

Requirements

  • The current README requires Python 3.11+.
  • Install google-adk and configure the selected model and deployment credentials.

Limitations

  • Compatibility and evaluation depend on the chosen model/tool stack.
  • Toolkit features do not establish that an application is safe or production-ready.

Cost and privacy notes

  • Model usage, tools, and deployed infrastructure are not included in the Apache-2.0 toolkit.
  • Review sessions, telemetry, and provider routing before processing confidential content.
