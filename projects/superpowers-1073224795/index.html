Superpowers

A composable skills framework for coding agents centered on clarification, design, planning, testing, and review. It changes an existing agent's workflow rather than supplying a new model.

Utilities

  • Guide a coding agent through design and implementation planning.
  • Apply test-driven and review-oriented development procedures.

Who it is for

  • Developers who want explicit process around an existing coding agent.

Requirements

  • Install the integration documented for your coding agent.
  • Provide a working model-backed agent and project test environment.

Limitations

  • Process instructions cannot guarantee test quality or correct implementation.
  • Subagent-driven work may expand execution scope; review permissions and budgets.

Cost and privacy notes

  • The skills are MIT; the host agent and model usage are separate costs.
  • The optional visual companion loads a remote logo for version telemetry; review its setting if network disclosure matters.

Illustrative example (untested)

Illustrative, not tested: use the design workflow for a small feature and review its test plan before implementation.
