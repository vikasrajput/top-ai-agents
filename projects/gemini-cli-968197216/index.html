Utilities

  • Use a terminal agent with supported enterprise Code Assist workflows.
  • Connect development tools through the documented CLI configuration.

Who it is for

  • Developers with supported organizational Code Assist access.

Requirements

  • Install a supported CLI release and configure the applicable Google account or credentials.
  • For organizational Code Assist access, set the required Google Cloud project.

Limitations

  • Do not assume older free-tier instructions apply: the README documents the June 2026 transition.
  • The README says the harness is not optimized for Gemini 4+ and should not be used for model benchmarks.

Cost and privacy notes

  • Access depends on the organization's license or configured provider billing; confirm eligibility before installing.
  • Review the CLI's telemetry and terms/privacy settings before exposing code.
