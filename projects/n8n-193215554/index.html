Utilities

  • Compose AI steps with ordinary business-system integrations.
  • Add logic, approvals, and custom code around agent actions.

Who it is for

  • Teams building integration-heavy workflows with operational ownership.

Requirements

  • Use the documented Docker deployment or a supported hosted account.
  • Configure persistent storage and narrowly scoped integration credentials.

Limitations

  • The Sustainable Use License is not a standard permissive open-source license.
  • Workflow credentials and automatic actions need careful access and retry design.

Cost and privacy notes

  • Cloud plans, enterprise features, model calls, and connected APIs may be billed separately.
  • Execution history can retain sensitive payloads; check retention and external-service routing.
