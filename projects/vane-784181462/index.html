Vane

A self-hostable answering engine combining web search, uploaded documents, and local or cloud models. It exposes source-cited answers through a browser interface.

Utility: Research; kind: platform.

Utilities

  • Search web, discussion, or academic sources for a question.
  • Ask questions about uploaded files with retrieved context.

Who it is for

  • Users who want control over an answering-engine deployment and model selection.

Requirements

  • Docker is the recommended installation route; a bundled SearxNG deployment is available.
  • Configure local Ollama models or supported cloud credentials.

Limitations

  • Citations do not guarantee that generated statements are supported.
  • Self-hosting does not make external search engines or cloud models private.

Cost and privacy notes

  • Local inference requires suitable hardware; cloud models and hosting may have separate costs.
  • Search requests, uploaded content, and model calls follow the configured services' data policies.
