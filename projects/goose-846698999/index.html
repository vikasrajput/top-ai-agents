goose

A general-purpose agent with desktop, CLI, and API interfaces. It combines model-provider choice with extensible tools, including MCP integrations, for coding and other local workflows.

Utilities

  • Use tools to inspect, edit, execute, and test development work.
  • Extend an agent session with supported MCP services.

Who it is for

  • Developers and technical users who want an extensible local agent.

Requirements

  • Install the desktop app or CLI for a supported platform.
  • Configure a model provider and only the extensions needed for the task.

Limitations

  • General-purpose tool access can affect files and external services.
  • Each extension brings its own permissions and dependencies.

Cost and privacy notes

  • Model subscriptions/API usage and external extensions may incur separate charges.
  • A local agent process can still send prompts and tool results to remote providers.
