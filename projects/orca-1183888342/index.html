Orca

A workspace for running coding agents side by side in isolated Git worktrees. It combines agent sessions, terminals, review tools, and optional remote/mobile control.

Utility: Agent operations; kind: platform.

Utilities

  • Compare multiple agent implementations without sharing one working tree.
  • Inspect changes and steer sessions from a unified interface.

Who it is for

  • Developers coordinating coding agents across local or remote repositories.

Requirements

  • Install the supported application and configure the coding agents you want to run.
  • Set up SSH or mobile integrations only if required.

Limitations

  • Worktree isolation does not isolate all credentials, network access, or external side effects.
  • Parallel sessions can multiply model usage and require careful merge review.

Cost and privacy notes

  • The MIT application is separate from agent subscriptions and remote-compute costs.
  • The README documents anonymous usage telemetry and opt-out guidance; review remote access and session-data handling.

Illustrative, not tested: give two agents the same small task in separate worktrees and manually review both diffs.
