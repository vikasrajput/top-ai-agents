Page Agent

A JavaScript agent that operates inside a web page using text-based DOM interaction. Its base integration does not require a headless browser or screenshots.

Utility: Browser automation; kind: framework.

Utilities

  • Embed natural-language control in an existing web application.
  • Assist with in-page navigation or form-filling tasks.

Who it is for

  • Web developers prototyping an in-product agent interface.

Requirements

  • Integrate the JavaScript package with a page you control.
  • Configure a supported model endpoint; multi-page features use additional integrations.

Limitations

  • DOM interaction does not guarantee compatibility with every custom widget.
  • The public demo endpoint is for technical evaluation and has separate terms.

Cost and privacy notes

  • Production model usage depends on the chosen endpoint; do not treat a testing API as a production entitlement.
  • DOM content can include customer or account data; keep secrets out of agent context.

Illustrative, not tested: add an agent to a test form and ask it to fill non-sensitive demonstration fields.
