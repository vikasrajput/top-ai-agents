Cline

A coding agent available through editor extensions, a CLI, a desktop app, and an SDK. Plan/act workflows and human approvals are central to its documented repository experience.

Utilities

  • Explore and edit code through editor or terminal sessions.
  • Build integrations using the same engine's SDK.

Who it is for

  • Developers who want agent tools with review controls across multiple interfaces.

Requirements

  • Install the interface appropriate to your editor or operating system.
  • Configure a supported model provider and repository access.

Limitations

  • Approval controls depend on the interface and operating mode; inspect the active configuration.
  • Tool access can extend beyond code editing into commands and browsing.

Cost and privacy notes

  • Apache-2.0 code does not include free model usage.
  • Repository text and tool results may reach configured model endpoints or connected services.
