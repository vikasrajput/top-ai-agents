agent-browser

A native browser-automation CLI designed to be called by AI agents. It supplies browser commands and snapshots rather than a complete autonomous agent on its own.

Utilities

  • Give a coding agent command-line access to browser navigation and inspection.
  • Run repeatable browser steps from scripts or agent tools.

Who it is for

  • Developers integrating browser tools into an existing agent.

Requirements

  • Install the native CLI and Chrome; Linux may need additional browser libraries.
  • Source builds require Node.js 24+, pnpm 11+, and Rust.

Limitations

  • An external agent must decide what commands to run.
  • Session profiles and browser control can expose authenticated data; restrict domains and actions.

Cost and privacy notes

  • The CLI's Apache-2.0 code is separate from any model or gateway billing.
  • Browser state and screenshots can contain sensitive information; avoid sharing authenticated captures unnecessarily.
