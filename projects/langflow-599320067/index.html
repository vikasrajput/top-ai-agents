Langflow

A visual builder for agents and workflows with API and MCP deployment surfaces. Components can be customized in Python while flows remain inspectable in a graphical interface.

Utility: Workflow and business automation; kind: platform.

Utilities

  • Compose and inspect model, retrieval, and agent flows visually.
  • Expose a workflow through an API or MCP server.

Who it is for

  • Developers prototyping agent applications with a visual authoring layer.

Requirements

  • Use the desktop app, Docker, or a Python 3.10-3.14 installation.
  • Configure model and database credentials and secure exposed endpoints.

Limitations

  • Custom Python components and exposed tools execute with deployment permissions.
  • A working visual flow is not evidence of production safety or answer quality.

Cost and privacy notes

  • Model calls, databases, and deployment infrastructure may incur charges.
  • Flow traces can contain prompts and document content; review observability and storage settings.

Illustrative example (untested)

Illustrative, not tested: connect a document retriever to a model, inspect intermediate results, and expose the reviewed flow as a tool.
