LibreChat

A self-hosted chat and agent workspace supporting multiple model providers, tools, and skills. Its current release also documents managed agent APIs and experimental attached code workspaces.

Utility: Personal agents and workspaces; kind: platform.

Utilities

  • Unify multiple model-backed conversations and agents in one interface.
  • Manage agent tools, files, and skills with deployment access controls.

Who it is for

  • Teams that can operate a multi-user conversational platform.

Requirements

  • Deploy the documented service stack and persistent stores.
  • Configure provider access, authentication, and permissions for agent tools.

Limitations

  • Attached code workspaces are described as highly experimental.
  • Provider support and role grants do not establish security for every connected tool.

Cost and privacy notes

  • Models, code workers, databases, and hosting can each contribute costs.
  • Conversations, attachments, traces, and worker files need explicit retention and access policies.

Illustrative example (untested)

Illustrative, not tested: configure a read-only agent for a non-sensitive knowledge base and compare cited answers with the documents.
